# Bhutan Cloud POS & Multi-Tenant ERP

A modern Point of Sale, Inventory, and Financial ERP system built with React, TypeScript, Tailwind CSS, and Supabase / Cloud Firestore backend support.

## Key Modules
- Multi-Tenant POS & Billing (RAMIS tax & Bhutan flat tax compliant)
- Superadmin Multi-Tenant Control Panel & Diagnostics (`Alt + 0`)
- Chart of Accounts & General Ledger Management
- Real-time Inventory & Stock Tracking
- Bank Reconciliation & Financial Year Management
